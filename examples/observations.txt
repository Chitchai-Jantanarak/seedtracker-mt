# observations.txt: one event per line, then the rnd() gap to the next event.
#
#   event [LIST] [include=A,B] [exclude=A,B]
#       LIST      values seen so far, 1..6, at most 5 (a partial prefix is fine)
#       include   values that appear somewhere in the event's five values
#       exclude   values that appear nowhere in the event's five values
#   gap N | gap A..B
#       rnd() calls between the previous event's last draw and the next event's
#       first draw. A missing gap line means gap 0.
#
# The last event is the one being predicted. More examples sit next to this file.
event 5,1,2,6,3
gap 0..40
event 2,4,1,3,5
gap 10..200
event 3
